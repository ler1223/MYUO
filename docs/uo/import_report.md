# Перенос навыков UO: что осталось приближением

Обновлено после переноса каталога (шаги 1–5 из `SONNET_PORTING_GUIDE.md`). Старый список приближений
`tools/uo_import.py` закрыт: навыки и пассивки теперь собирают `tools/uo_fill_passives.py` (пассивки, навыки-ответы,
эффекты), `tools/uo_fix_skills.py` (исправления активных навыков), числа сверяет `tools/uo_audit_skills.py`
(`tests/test_uo_audit.py` держит расхождения на нуле). Перезапуск `tools/uo_import.py` затёр бы эти правки —
не запускайте его на готовых данных.

## Не сделано

- **Celestial Light** — пассивка остаётся заглушкой: текст игры («Unleash its true power amidst a sea of miasma»)
  служебный, настоящего действия в записи нет.
- **Лечение выше максимума HP** — Limited Heal («до N% выше максимума», число в тексте игры не подставилось) и
  Healing Pursuit («до 150%») лечат до максимума.

## Приближения

| Навык / пассивка | Как в игре | Как сделано |
|---|---|---|
| Quick Impetus | союзник действует ещё раз | союзнику +2 AP |
| Vanquish | −2 AP только ослабленным целям | −2 AP всем задетым |
| Royal Guard, Nocturnal Guard, Aerial / Bestral / Cavalry Guard | число «%s» в тексте игры не подставилось | лечение 10% HP (Royal Guard), +1 PP (остальные) |
| Hastened Action / Cast, Quick Cast | «максимум инициативы на следующее действие» | +1000 инициативы до конца хода |
| Heavy / Aerial Alignment, United Front | баффы по числу целей | ступени: считаются живые бронированные / летающие союзники отряда или перевес врагов; ряд владельца |
| Flame / Ice / Thunderous / Dark Conferral | магический урон и состояние в атаке союзника | магическая добавка (+50% mag. atk к силе) и состояние на задетых при попадании (`on_hit`) |
| Sanguine Conferral | вампиризм атаки союзника | лечится владелец пассивки на 50% нанесённого урона |
| Honed Shield | союзнику 100% шанс блока и пронзающие удары не бьют | эффект даёт +100 к шансу блока и тег `nullify_pierce` |
| Quick / Holy / Saints Barrier, Protection, Circle Barrier | урон −25 / 50% на одну атаку | флаг эффекта `reduce:N` на один удар любого типа |
| Phalanx / Aerial Shift | бафф ряда | ряд атакованного союзника, бафф только кавалерии / летающим |
| Assassin's Nail, Grisly Fire / Poison | «+N силы и крит» в условии | сила растёт, критический удар не гарантируется |
| Sylphic Wind и другие «феи» | призванные существа | стаки эффекта `uo_faerie` (не больше 5, число в игре неизвестно); сбрасывает только Elemental Roar |
| Mirror Weakness | вернуть все снятые дебаффы цели | дебаффы переносятся на того, кто наложил последний |
| Chaos Unending | случайное состояние каждому врагу | одно из восьми состояний (яд, ожог, заморозка, оглушение, слепота, три печати) |
| «Атакует двух / трёх врагов» (Dual Shot, Magick Missile…) | неизвестно, случайные ли цели | выбранный враг + случайные другие |

Остальные расхождения с вики и игрой сверяются автоматически (`python tools/uo_audit_skills.py`).
