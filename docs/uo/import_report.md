# Перенос классов UO: отчёт

Классов: 60, навыков: 135, пассивок: 100, эффектов: 64. Ниже — где пришлось приблизить (`python tools/uo_import.py`).

- **binding_guard**: «следующая атака накладывает печать блока» — печать сразу атаковавшему
- **boon_of_the_faeries**: феи заменены приближением: «Grants the user +1 summoned faeries.»; лечение группы — одним навыком по первому союзнику
- **circle_barrier**: «урезать урон одной атаки» — принудительный блок (только физический урон)
- **compounding_curse**: сила не указана в вики — взята 100
- **defensive_curse**: сила не указана в вики — взята 100
- **deflect**: из нескольких эффектов взят первый
- **demonic_pact**: плата HP за AP не переносится: просто +1 AP
- **discharge**: мощь от поглощённых баффов — фиксированные +50%
- **dual_shot**: две-три случайные цели заменены одиночной целью с теми же ударами
- **elemental_roar**: феи заменены приближением: «Potency increases with faerie count (+30 per faerie).»; феи заменены приближением: «This dismisses all summoned faeries.»
- **faerie_heal**: феи заменены приближением: «Grants the user +1 summoned faeries.»
- **first_aid**: конца боя нет: срабатывает в конце раунда, раз за бой
- **glacial_rain**: заряд (действие в конце раунда) не переносится: обычный удар
- **holy_barrier**: «урезать урон одной атаки» — принудительный блок (только физический урон)
- **icicle_arrow**: две-три случайные цели заменены одиночной целью с теми же ударами
- **life_blow**: конца боя нет: срабатывает в конце раунда, раз за бой
- **magick_missile**: две-три случайные цели заменены одиночной целью с теми же ударами
- **medical_aid**: конца боя нет: срабатывает в конце раунда, раз за бой
- **night_vision**: ночь/день не переносятся: «At night, makes the targets' next attack a truestrike.»
- **nocturnal_strike**: ночь/день не переносятся: «Grants the user +1 PP PP at night.»
- **offensive_curse**: сила не указана в вики — взята 100
- **parting_blow**: конца боя нет: срабатывает в конце раунда, раз за бой
- **parting_resurrection**: конца боя нет: срабатывает в конце раунда, раз за бой; воскрешения нет: союзники получают «пережить смертельный удар»
- **passive_curse**: сила не указана в вики — взята 100
- **passive_miracle**: события «пассивка союзника» нет: реагирует на навык союзника
- **primus_edge**: феи заменены приближением: «If the user is at 100% HP, grants the user +1 PP PP and +1 summoned faeries.»
- **pursuit**: сила не указана в вики — взята 100
- **quick_cast**: «макс. инициатива на ход» — +100 инициативы на весь бой
- **quick_curse**: наложено только первое из нескольких состояний
- **rage_of_the_faeries**: феи заменены приближением: «Inflicts Stun, grants the user +1 summoned faeries.»
- **restore**: события «пассивка союзника» нет: реагирует на навык союзника
- **saints_barrier**: «урезать урон одной атаки» — принудительный блок (только физический урон)
- **sanguine_arts**: вампиризм следующей атаки — сразу лечение 25% HP
- **selfless_heal**: лечение группы — одним навыком по первому союзнику
- **sylphic_wind**: феи заменены приближением: «Grants the user +1 summoned faeries.»
- **triple_counter**: две-три случайные цели заменены одиночной целью с теми же ударами
- **wing_rest**: конца боя нет: срабатывает в конце раунда, раз за бой
